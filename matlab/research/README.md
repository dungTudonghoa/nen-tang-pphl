# MATLAB Research Workspace

This area supports learning, derivation, reference/oracle implementations, experiments, and visualization.

Allowed research techniques include MATLAB toolboxes, brute force on small instances, slow readable reference implementations, scripts, plots, profiling, and non-codegen constructs.

Research evidence can challenge or validate a hypothesis, but research code does not become production simply because observed outputs are correct. Production candidates move into `matlab/+pphl/` only through an accepted interface, test-first implementation, and relevant codegen verification.

Reproducible experiments should record configuration, random seed when applicable, dataset/generator version, and the revision under study.
