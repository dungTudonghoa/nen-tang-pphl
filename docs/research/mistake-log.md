# Mistake Log

Record mistakes that reveal a meaningful gap in the learner's mental model. Do not record ordinary typos unless they expose a recurring conceptual problem.

## Record Template

### M-XXX: Short title

**Date:** YYYY-MM-DD

**What I believed**

State the prior mental model in the learner's own words.

**Evidence that contradicted it**

Record the observation, test failure, derivation, or reference evidence.

**Smallest counterexample**

Reduce the failure to the smallest useful instance.

**Root cause / missing concept**

State what was misunderstood rather than only where the code failed.

**New invariant or rule learned**

Write the corrected mental model.

**Regression or future evidence**

Link the test, experiment, or transfer exercise that should catch the mistake again.
