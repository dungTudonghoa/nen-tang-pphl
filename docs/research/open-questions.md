# Open Questions

An open question is not permission for an AI agent to invent a default. Promote an answer into `docs/product/` or `docs/decisions/` only after human acceptance.

- Q-001: What exact semantics define a geometric conflict in the neutral assignment model?
- Q-002: Does endpoint touching count as a geometric conflict?
- Q-003: What numeric representation, precision, and equivalence tolerance are required?
- Q-004: What production problem-size bounds must interfaces support?
- Q-005: What dynamic-memory or bounded-allocation policy is required?
- Q-006: What execution-time budget, if any, must production satisfy?
- Q-007: What deployment hardware, operating system, and runtime environment will generated C++ target?
