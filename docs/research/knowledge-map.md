# Knowledge Map

## Status Vocabulary

- `UNSEEN`: not yet studied in this project.
- `LEARNING`: active study; mental model is still being formed or corrected.
- `IMPLEMENTED`: the learner has produced an implementation attempt; correctness is not implied.
- `VERIFIED`: accepted evidence supports the implementation for a defined scope.
- `UNDERSTOOD`: the learner can explain the governing idea, work a representative example, describe a failure/counterexample, and transfer the concept to a related case.

## Promotion Rule

Do not promote a concept to `UNDERSTOOD` solely because code or generated output passes. Link concrete learner evidence and meaningful counterexamples or transfer exercises.
